This README lists the tools that can be used with CTE

1) learn-mode-policy-builder tool - used to process audit logs which in turn are used to tune the policies and security rules based on the access operations performed over a file/directory.

2) Parse-RansomwareLog tool - used to parse all of vmd logs for flagged rwp processes and generate a JSON for the processes and resource sets extracted from the vmd logs which can be directly pasted in to CM API trusted process sets for getting rid of warning generated in client.
